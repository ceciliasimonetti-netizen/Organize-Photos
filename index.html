Como Funciona este Projeto?

Guia simples em 4 passos para conectar e implantar seu projeto com segurança no GitHub Pages.

1

Google Cloud Console

Crie um projeto no Google Cloud e ative a **Google Photos Library API**.

2

Credencial OAuth 2.0

Gere um Client ID de Aplicação Web e adicione a URL do seu GitHub Pages em "Origens JavaScript autorizadas".

3

Varredura e Hashing

O app lê os metadados das fotos e compara miniaturas para localizar arquivos repetidos sem deletar nada direto da nuvem.

4

Deploy no GitHub

Faça o push deste código HTML para um repositório no GitHub e ative o **GitHub Pages** nas configurações.
